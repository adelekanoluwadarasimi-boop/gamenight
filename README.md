# GameNight - Friend's Leaderboard & Tournament Manager

GameNight is a web application designed to track game night scores, run tournaments, maintain leaderboards, and determine who reigns supreme among friends.

## 🚀 Features

- **🏆 Real-Time Leaderboard**: Ranks players dynamically by total score, games played, and win rate.
- **⚡ Instant Local Tournament Mode**: Seamless offline/local storage fallback. Play tournaments immediately on the same device without needing cloud configuration.
- **🌐 Supabase Cloud Sync**: Real-time cross-device sync, cloud screenshot proofs, and remote user authentication.
- **📱 Responsive Mobile & Desktop UI**: Glassmorphic dark theme with mobile-optimized card standings.
- **📸 Anti-Cheat Proof Uploads**: Proof screenshots displayed with an inline image modal viewer.
- **🎮 Custom Games Support**: Choose between featured games (Blox Fruits, Whot, Jujutsu Infinite, Shadow Boxing) or enter any custom game title.
- **🔍 Instant Search**: Real-time search across recorded games and players.

## 🛠️ Quick Start (Play Right Now)

### Option 1: Direct in Browser (Local Tournament Mode)
1. Open [`index.html`](index.html) directly in any web browser.
2. Click **"Login / Join"** in the top right.
3. Switch to the **"Sign Up"** tab to create player accounts for you and your friends.
4. Click **"+ New Score"** to record results, enter scores, and upload screenshot proofs.
All player accounts, standings, and screenshots are safely preserved in browser storage.

## ☁️ How to Connect Your Own Supabase Cloud Database

If your friends want to submit scores from their own phones or computers over the internet, connect a free Supabase database:

### 1. Create a Supabase Project
1. Go to [supabase.com](https://supabase.com) and sign in or create a free account.
2. Click **"New Project"**, pick your region, set a database password, and create the project.

### 2. Disable Email Confirmation (Important for instant signups)
1. In your Supabase dashboard, open **Authentication** in the left sidebar.
2. Select **Providers** > **Email**.
3. Toggle **OFF** `Confirm email`.
4. Click **Save**.

### 3. Create the Database Table
1. Open the **SQL Editor** in the left sidebar.
2. Click **New query**, paste the following SQL script, and click **Run**:

```sql
create table games (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  game text not null,
  winner text not null,
  score integer not null,
  date text not null,
  user_id text,
  screenshot_url text
);

-- Enable Row Level Security (RLS)
alter table games enable row level security;

-- Anyone can view games and the leaderboard
create policy "Allow all read" on games for select using (true);

-- Players can submit new scores
create policy "Allow insert" on games for insert with check (true);

-- ONLY admin (adelekanoluwadarasimi@gmail.com) can edit or delete scores
create policy "Admin only update" on games for update using (
  auth.jwt() ->> 'email' = 'adelekanoluwadarasimi@gmail.com'
);
create policy "Admin only delete" on games for delete using (
  auth.jwt() ->> 'email' = 'adelekanoluwadarasimi@gmail.com'
);
```

### 4. Create the Storage Bucket for Screenshot Proofs
1. Go to **Storage** in the left sidebar.
2. Click **New bucket**.
3. Set the bucket name to `proofs`.
4. Toggle **Public Bucket** to **ON**.
5. Click **Save**.

### 5. Update Your Credentials
1. Go to **Project Settings** (gear icon) > **API**.
2. Copy your **Project URL** and **`anon` public key**.
3. Open [`script.js`](script.js) and replace lines 2-3:
```javascript
const SUPABASE_URL = 'https://your-project-id.supabase.co';
const SUPABASE_KEY = 'your-anon-key-here';
```
The application will automatically switch to **🟢 Cloud Connected** mode!
